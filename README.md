Проект по автоматизации бригады ремонт под ключ

Репозиторий учебного проекта по автоматизации бизнес-процессов ремонтной бригады. Система помогает вести учёт клиентов, объектов, составлять сметы, следить за этапами работ, расходом материалов и фиксировать оплаты с гарантийными заявками.

 Технологии, которые использовали
* Язык и платформа: C# (WPF), .NET Framework / .NET Core
* Паттерн: MVVM
* База данных: MS SQL Server
* Подключение к БД: ADO.NET или Entity Framework
* Проектирование: Figma (интерфейс), draw.io / Visio (схема БД)

 Модули в приложении

В программе работают 9 модулей:
1. Клиенты: Добавление, изменение, удаление заказчиков. Есть поиск по имени и телефону.
2. Объекты: Карточки квартир/домов, где идет ремонт. Указывается площадь, сроки и статус.
3. Виды работ: Справочник с ценами (например, штукатурка, стяжка) и нормативами.
4. Сметы: Составление списка работ для объекта. Считает общую сумму сама, если поменять объёмы.
5. Материалы: Склад (остатки, цены, поставщики). Можно привязать к нужной смете.
6. Бригады и сотрудники: Список рабочих, их роли (мастер, бригадир), телефоны и ставки.
7. Этапы работ: Шкала готовности объекта по этапам (демонтаж, отделка и т.д.) с процентами.
8. Доп. работы и гарантия: Всё, что вылезло за рамки сметы, плюс учёт жалоб по гарантии.
9. Оплаты и отчёты: Фиксация денег (авансы/расчёты) и простые отчёты по выручке и срокам.

Структура БД (Таблицы)

* Client — клиенты
* Object — объекты ремонта
* WorkType — виды работ
* Estimate — сметы
* EstimateItem — строки в смете
* Material — материалы
* EstimateMaterial — материалы в конкретной смете
* Team — бригады
* Employee — рабочие
* WorkStage — этапы ремонта
* ExtraWork — доп. работы
* WarrantyClaim — гарантия
* Payment — платежи

 Как запустить проект у себя

 Шаг 1. Накатить базу данных
Можно сделать это двумя путями:

 Вариант А (Скриптами):
  1. Открываем SQL Server Management Studio (SSMS).
  2. Создаем пустую базу RemontDb.
  3. Открываем файл database/create_tables.sql и жмем Execute (Выполнить).
  4. Потом открываем файл database/seed_data.sql и тоже выполняем его, чтобы появились тестовые строчки.

 Вариант Б (Через бэкап):
  1. Кликаем правой кнопкой по папке Databases в SSMS -> Restore Database.
  2. В источнике выбираем Device и указываем путь к нашему файлу database/RemontDb.bak.
  3. Жмем ОК и база восстановится.

 Шаг 2. Поменять строку подключения
1. Ищем в проекте файл конфигурации (обычно это App.config).
2. В теге connectionStrings правим параметр Data Source — пишем туда имя своего локального SQL-сервера:
   ```xml
   <connectionStrings>
     <add name="DefaultConnection" 
          connectionString="Data Source=ИМЯ_ВАШЕГО_КОМПЬЮТЕРА;Initial Catalog=RemontDb;Integrated Security=True;" 
          providerName="System.Data.SqlClient" />
   </connectionStrings>
   ```
 Шаг 3. Запуск в Visual Studio
1. Открываем файл RemontSystem.sln через Visual Studio 2022.
2. Ждем, пока студия подгрузит все зависимости.
3. Проверяем, чтобы сверху стоял Debug.
4. Нажимаем клавишу F5 (или зеленую стрелочку Start).
